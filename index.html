AI DESIGN SKILL

Make your AI build websites that don't look AI-made

Hallmark is an open-source design skill for Claude Code, Cursor, Codex and OpenCode. Install it once, and your AI designs pages from 50 real themes, builds around what the visitor came to do, and checks the result in a real browser before handing it back.

Source: Get Hallmark on GitHub →
github.com/Nutlope/hallmark

Before you start

What you need

  • One AI coding tool: Claude Code, Cursor, Codex or OpenCode.
  • Node.js 18 or later. Check by running node -v in your terminal. If you don't have it, download it from nodejs.org.
  • Google Chrome (optional). Hallmark uses it to check your page at different screen sizes.
  • About 2 minutes.

Step-by-step

How to set it up

Copy each command, paste it into your terminal, and press Enter.

STEP 1

Install Hallmark

This one command installs it for every tool you have and every project:

npx skills add nutlope/hallmark -g
Only want it in one project? Open your terminal inside that project folder and run the same command without -g.

OR · ONE TOOL ONLY

Pick your tool

Use one of these if you only want Hallmark in a single tool. Skip this if you already ran Step 1.

Claude Code

npx skills add nutlope/hallmark -g --agent claude-code

Cursor

npx skills add nutlope/hallmark -g --agent cursor

Codex

npx skills add nutlope/hallmark -g --agent codex

OpenCode

npx skills add nutlope/hallmark -g --agent opencode
Claude Code plugin option: inside Claude Code, run these two lines one at a time. You'll then call it with /hallmark:hallmark.
/plugin marketplace add nutlope/hallmark
/plugin install hallmark@hallmark

STEP 2 · OPTIONAL

Turn on the browser checks

Hallmark can open your page in Chrome and check it at eight screen sizes before it hands it back. If you have Chrome, run:

npm i -g puppeteer-core
Skipping this is fine. Hallmark still runs its other design checks without it.

STEP 3

Restart your tool and call Hallmark

Close and reopen Claude Code, Cursor, Codex or OpenCode so it picks up the new skill. Then type:

ToolType this
Claude Code/hallmark + your prompt
Cursor/hallmark + your prompt
OpenCode/hallmark + your prompt
Codex$hallmark + your prompt

You can also just describe a new page and it starts on its own. Copy-paste prompts are below.

Shortcut

Let your AI install it for you. Paste this into Claude Code, Cursor, Codex or OpenCode and it will do Steps 1 and 2 for you.

Install the Hallmark design skill for me from https://github.com/Nutlope/hallmark 1. Read the README in that repo first. 2. Check that I have Node.js 18 or later. If I don't, stop and tell me how to install it. 3. Run: npx skills add nutlope/hallmark -g 4. If Google Chrome is installed on this computer, also run: npm i -g puppeteer-core 5. Tell me if I need to restart this tool, how to call Hallmark here, and give me one example prompt to try.

Copy & paste

Prompts to start using it

Replace the parts in [brackets] with your own details. In Codex, use $hallmark instead of /hallmark.

Build a new landing page

Hallmark offers you three themes that fit, then builds the page.

/hallmark build a landing page for [your business], which [what you sell or do]. The main thing visitors should do is [book a call / buy / join the waitlist].

Get a fully custom design

Say "custom" and it skips the themes and designs from your prompt alone.

/hallmark build a custom portfolio site for [your name], a [what you do]. Show [your best projects] and end with a way to contact me.

Redesign a page you already have

It keeps your content, links and forms, and changes the design and layout.

/hallmark redesign ./index.html

Restyle but keep the layout

Add "keep the layout" for a new look on the same structure.

/hallmark redesign ./index.html keep the layout

Just fix what looks AI-made

Add "polish" for small fixes only.

/hallmark redesign ./index.html polish

Get a report without changes

Audit only tells you what's wrong. It doesn't edit anything.

/hallmark audit ./index.html

Tip

Give Hallmark your real material: photos, screenshots and real numbers. It won't make up stats, reviews or logos, so it will ask you for them before building.

Stuck?

FAQ & fixes

It doesn't start on its own

Name it in your message, like use hallmark to build ..., or start with /hallmark ($hallmark in Codex). Restart your tool first if you only just installed it.

"npx: command not found" or a Node error

You need Node.js 18 or later. Install it from nodejs.org, close and reopen your terminal, then run the Step 1 command again.

The browser checks are skipped

Install Google Chrome and run npm i -g puppeteer-core (Step 2). Without them, the other design checks still run.

Will it change my existing website?

No. Hallmark only touches an existing design when you name it with /hallmark redesign. Use /hallmark audit if you only want a report.

Where can I get more help?

See the GitHub repo and its issues page, or browse all 50 themes at usehallmark.com.
